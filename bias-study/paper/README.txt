SE4ALL 2027 — IEEE Conference LaTeX Project

Files:
- main.tex: Final manuscript source
- fig1.png: Corrected experimental design
- fig2.png, fig3.png, fig4.png: Original reported figures
- IEEEtran.cls: IEEE conference document class
- IEEEtrantools.sty: IEEE companion style (provided, not required by main.tex)

To build: open main.tex in Overleaf with the other files at the project root, then compile using pdfLaTeX, or run:
  pdflatex -interaction=nonstopmode main.tex
  pdflatex -interaction=nonstopmode main.tex

All figures are already referenced by main.tex. The project does not require external bibliography files.
The paper uses IEEEtran 10pt conference settings.
